# 盲测基准（50部小说的盲测基准）

本计划最大的赌注是“这个系统能否真正看穿故事的价值”。为了验证这一点，我们设计了基于**文学史50部作品**的**盲测基准**。结果将累积在本文档中，并用于各评估者严格程度的调整（校准）。

## 盲检流程（双重盲检的运用）

1. 将各作品的**开头＋摘要**作为**移除作者名・作品名的匿名文本**输入（第一重盲检）。使用 `utils/anonymize.py` 进行预处理。
2. 系统由13位评估者按照**结构性标准**（第二重盲检）进行评价，并推导出分类。
3. 仅在评价**结束之后**，才与文学史标签（ground truth）对照，测量一致率。

```
入力: 「ある男が朝目覚めると、身体が別のものへ変容していた。家族は…」（匿名・構造的記述）
システムの盲検分類: Discovery Target / Innovation
評価後の照合: 文学史ラベル = Innovation
一致: ✓
```

※ 如果在输入中包含作品名，系统就会锚定于其名声而推测出正确答案，**验证的意义就会丧失**。盲检是验证的前提。

## 选取标准（4象限 × 类型）

| 分类 | 选取标准 |
|------|---------|
| **Discovery Target** | 生前境遇不佳・评价不高，但在后世被重新评价为名作的作品群 |
| **Innovation** | 从发表当时至今，始终获得一贯高评价的作品群 |
| **Current Success** | 同时代获得高评价・成为畅销书，但未能流传后世的的作品群 |
| **Low Signal** | 发表后几乎无人阅读、也几乎没有得到评价的作品群 |

为各作品赋予基于文学史定论的**分类标签**（ground truth）。标签仅限于能从多部文学史和选集的记载中确认的内容。标签**仅用于对照时**使用。

※ 该标签由人类的文学史共识在外部赋予，不影响系统的评价标准（结构性描述）。

## 一致判定与目标值

- 测量系统的盲检分类与文学史标签之间的**一致率**。
- **目标值: 一致率 70%**（实现该目标作为收费化的条件）。

### 「一致率70%」的操作性定义（使其可验证）

将**一致率**按如下方式**操作性定义**：

- **一致**: 系统的盲检分类（Innovation / Discovery Target / Current Success / Low Signal）与文学史标签完全一致的情况。
- **边界情况的处理**: 被分类到当前价值35-44边界带的的作品，**计为不一致**（无法确定给出标签的作品不计入“一致”。保守计数）。`borderline` 的操作性定义: `current_value_score` **大于等于35且小于45**，或 `hidden_potential_score` **大于等于35且小于45** 的作品。
- **分母**: 作为评价对象的全部50部作品（无除外）。
- **报告**: 将 `一致数 / 50` 作为一致率记录，并追记到本文档的累积表中。同时记录边界情况的数量。
- **可再现性**: **固定50部作品的划分（split）与随机种子（seed）**，确认多次执行得到相同结果。

通过这一定义，“70%”不再是模糊的目标，而是可追踪・可再现的指标。

### 70%这一目标值的依据（与基线的对比）

“70%”被设定为显示**超越偶然一致率（机会水平）的判别力**的阈值。

- 若4个分类大致均匀分布，偶然一致率约为25%。70%是其**约2.8倍**，是偶然几乎不可能达到的水平。
- 不过，由于文学史标签基于人类共识，考虑到标签本身的波动（标注者间的不一致），**同时记录实测的偶然一致率・标注者间一致率（例如 Cohen's kappa）**。
- 目标值是暂定值，将在基准实测后重新校准（`references/scoring-strictness.md`）。这种可校准性本身就是设计的一部分。

### 小样本（n）方差估计的注意事项

当评估者数量较少时（如情节评价，plot模式下为8位），Story Vector的方差**成为小n下的估计，可能不稳定**。

- 方差阈值（100/400）的判定，**仅在评估者分数有3个以上的维度**进行（参照 `references/scoring-strictness.md`）。
- 在基准中，报告一致率时**同时记录各作品的评估者数（n）**，并注明n较小（<4）时的可靠性局限。

## 不一致的分析（反馈到校准）

- 不要仅凭一致率判断。**不一致发生在何处**最为重要。
- 系统判定为 Current Success、但文学史上属于 Innovation 的作品 → 分析在意义・情感维度上漏掉了什么。
- 系统判定为 Discovery Target、但文学史上属于 Low Signal 的作品 → 过度乐观的风险。将判断标准严格化。
- 不一致的分析也用于**检测锚定偏差**。
- 基准结果累积在本文档中，用于各评估者严格程度的调整（Phase 2）。

## 与人类编辑的相关性（辅助性验证）

- 如果可能，就数部作品测量人类编辑・批评家的评价与系统分数之间的相关性。
- 这是对“一致率”的辅助，并非要让系统替代人类判断（合议不下判决。判断属于人类的责任）。
