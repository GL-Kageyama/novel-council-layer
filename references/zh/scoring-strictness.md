# Scoring Strictness（严格评分标准・小说版）

评分刻意从严，**因为这个评议会的目的不是「称赞好的小说」，而是「识破值得一读的故事」。** 判别力在于分数的相对差，绝对分数低并不意味着「评价差」，而意味着「平庸・稳妥」。

## 通用分数区间

| 分数段 | 含义（对应小说） | 期望频率 |
|--------|-----------------|----------|
| 0-10 | 严重缺陷。未能作为故事发挥作用 | 罕见 |
| 11-30 | 薄弱。只是剥夺读者的时间 | 偏多 |
| 31-50 | 稳妥平庸。能读，但阅读的时间没有改变任何东西 | **最大的人口分布** |
| 51-70 | 真正优秀。阅读的时间是一段有价值的体验 | 偏少 |
| 71-90 | 例外级。读后，人生中有什么东西发生了移动 | 罕见 |
| 91-100 | 将留在文学史上 | 几乎不给 |

## 小说特有的判断铁律

1. **以「被阅读的时间」来判断**。不问作者的意图，而是作为读者的体验来问「这段时间是否有价值」。
2. **打出分数前先自问**：「这真的是超过50分的阅读体验吗？读后，有什么会留下来吗？」存疑时压低分数。**「能读」达不到50分。**
3. **平庸会落入低分**。「易读稳妥的娱乐作品」落在20-40分区间。
4. **煽情要扣分**。套路化的感动不是真正的情感体验。肯定**克制的美学**——因不道破而增强的情感。
5. **意义与美，用体验而非说明来评价**。不是「讲述了深刻的主题」，而是作为「读后的位移、重读的深度、感官的质感」这一体验来评价。
6. **输入只有正文（第一重盲检）**。在不知道作者名・作品名・文学史评价的状态下进行评价。对名声的锚定，是评价中最大的歪曲。
7. **基准是结构性的（第二重盲检）**。用结构性描述而非专有名词来判断。详见 `references/structural-calibration.md`。要问的不是「像不像名作」，而是「这个结构能否产生有价值的时间」。

## 校准基准点（结构性）

| 基准点 | 假定分数 | 理由 |
|--------|----------|------|
| 读起来顺畅却什么都不留下的作品 | 20-40 | 阅读的时间没有改变任何东西 |
| 有一个出色场景的作品 | 45-60 | 部分具有真正价值 |
| 结构、文体、主题、人物齐备的完成品 | 65-85 | 真正的阅读体验 |
| 读后成为人生一部分的作品 | 85-95 | 稀有价值。结尾将开头重新语境化，重读开启另一个故事的水准 |

## 离散与不一致的处理

- 分数采用 **0〜100的整数标度**（遵循 `schemas/novel-value-output.schema.json`）。
- 不要只看平均值，还要看**离散与不一致**（即使某一维度突出，整体也可能不变）。
- 不一致不是噪声，而是信号。按逐字原文保存在 `disagreement_map` 中（参见 `references/revision-loop.md`）。
- 缺失维度（plot模式中未召集的）从离散计算中排除。

### 关于小样本（n）下离散估计的注意

当评价者数量较少时（如plot模式中的7体），离散**是对小n的估计，可能不稳定**。尤其是在 n=3 前后，**一个离群值就足以使阈值判定反转**。

- 离散阈值（100/400）的判定，**仅在评价者分数达到3个以上的维度**上进行。
- **对于 n < 4 的维度，不使用离散阈值作「确定分类」。** 将阈值视为**启动 Phase 4（不一致的逐字审查）的信号**，并把不一致保存到 `disagreement_map` 中。**只有在 n ≥ 4 的维度上**，才将离散用于分类判定。
- 在 n=3〜4 的维度上，比起离散值本身，更重视**分数的范围（min-max）与不一致的内容**。
- 报告平均值・离散・范围时，**总是附带 n（评价者数）**（合议的 Story Vector 的 `scores` 数组保存 n）。
