**v1 初案**

```
この世界では、人間は生まれるとき、一生に話せる言葉の数が決まっている。
平均はおよそ六万語。ほとんどの人は、それを四十歳前後で使い切る。
言葉を使い切った者は「黙者」と呼ばれ、身振りと筆談で暮らす。

主人公・白瀬悠（しらせゆう）は「言葉仲介人」——言葉を惜しんで余した者から、
必要とする者へ言葉を売買する職業。彼自身は物心ついたときから言葉を
惜しんで使い、いまだに七割の言葉を残している。彼は決して自分の言葉を
「本心を語る」ためには使わない。

ある日、悠は「最後の台詞」の取引を依頼される。依頼者は言葉を使い切って
三日後に死ぬ老女。彼女が残した言葉はただ一つ、「ごめんなさい」。
それは五十年前に彼女が黙って別れた娘——いまはもういない娘——に
届けたい言葉だという。

悠は言葉を届ける旅に出る。取引には決まりがある。仲介人は預かった言葉を、
その言葉の「本来の受け取り手」以外に渡してはならない。そして、老女の娘は
もういない。

旅の途中、悠は「言葉を使い切らない」理由を持つ者たちと出会う。
亡くなった妻への言葉をいまだに話しきれない男。生まれてくる子のために
言葉を残そうとする妊婦。それぞれの「残した言葉」の意味を、悠は仲介人として
ではなく、一人の人間として聞くことになる。

最後に悠は、受け取り手のいない「ごめんなさい」をどう届けるのか——そして、
彼自身が七割も残した言葉を、なぜ本心のために使わなかったのか、という
問いに直面する。
```

**v2 改訂案（revision_directionを反映）**

```
この世界では、人間は生まれるとき、一生に話せる言葉の数が決まっている。
平均はおよそ六万語。言葉を使い切った者は「黙者」になる——死ぬのではなく、
生きている間に「声」を失う。声を失う恐怖から、言葉を売買する市場が生まれた。
言葉は通貨であり、資産であり、ときに武器になる。

主人公・白瀬悠は「言葉仲介人」。他人の言葉を取引しながら、自らの七割の言葉を
貯め込んでいる。彼が本心のために言葉を使わない理由——それは八歳のとき、
母が言葉を使い切る間際に残した「ごめんね」を、返す言葉を惜しんで黙ったまま
受け取れなかった記憶に遡る。その「ごめんね」は、応答しなかったために、
いまだに誰にも届いていない。

ある日、悠は老女の依頼を受ける。「最後の台詞」の取引。老女は言葉を使い切って
死ぬ——老衰ではなく、九十歳の寿命。彼女が残した最後の一語は「ごめんなさい」。
五十年前、彼女は娘を黙って置いて家を出た。娘は後に生まれた子のために言葉を
残し、使い切って黙者になり、やがて亡くなった。悠はこの事実を知らない——
彼は、娘がまだ生きていると思って旅に出る。

規則は厳格だ。仲介人は預かった言葉を「本来の受け取り手」以外に渡してはならない。
受け取り手はいない。だが旅の途中、悠は「届かない言葉を送る方法」を知る者たちと
出会う。

・言葉をわざと浪費する男。亡き妻のために毎日「おはよう」と言葉を使い続ける。
　「届かない言葉を届ける唯一の方法は、使うことだ」と悠に教える。
・言葉で嘘をつく商人。言葉を買って偽りの告白を売る。「言葉の価値は受け取られる
　ことではなく、賭けられることにある」と嘲る。
・生まれてくる子のために言葉を残す妊婦。受け取り手のいない言葉こそが、最も誠実な
　言葉になりうると示す。

そして悠は、自分自身が八歳のとき「ごめんね」を受け取れなかった者であることに
気づく。老女の「ごめんなさい」は、応答しなかった誰かを探しているのかもしれない。

三日目、老女が死ぬ。言葉は届かなかった。悠は規則の「精神」を読み替え、
「ごめんなさい」を、受け取り手である「かつて応答しなかった自分」のために費やす。
彼は初めて、自分の言葉を本心のために使う。七割のうち、ほんの一語を。

受け取られることのない言葉に、意味はあるのか——物語はその問いを、開いたまま
閉じる。
```

**v3 改訂案（v2評価の修正を反映）**

```
この世界では、人間は生まれるとき、「生涯に話せる言葉」の口数が割り当てられる。
平均はおよそ百万語。一日に数百語を目安に話すのが礼儀であり、言葉は通貨であり、
資産であり、ときに武器である。言葉を使い切った者は「黙者」になる——死ぬのでは
なく、生きている間に「声」を失う。社会は沈黙に適応している。長い沈黙は失礼では
なく、分別である。

言葉は「応答」によって届く。使うことは届けようとする行為であり、応答されなければ
言葉は宙に残る。受け取るという行為は、応答という代価を払うことである。

主人公・白瀬悠は「言葉仲介人」。他人の言葉を預かり、受け取り手に届ける。自らの
言葉は、八歳のとき母が残した「ごめんね」に応答しなかった日から、一度も本心の
ために使っていない。その「ごめんね」は、応答されなかったために、今も誰にも
届いていない。

ある日、悠は老女の依頼を受ける。「最後の台詞」の取引。老女は九十歳で、寿命が近い。
彼女は生涯の残りの言葉をすべて費やして、たった一語「ごめんなさい」を残した。
五十年前、彼女は娘を黙って置いて家を出た。娘は生まれてくる子のために言葉を残し、
使い切って黙者になり、やがて亡くなった。悠はこの事実を知らない——彼は、娘がまだ
生きていると思って旅に出る。

規則は厳格だ。仲介人は預かった言葉を「本来の受け取り手」以外に渡してはならない。
受け取り手はいない。

旅の途中、悠は「届かない言葉」をめぐる者たちと出会う。

・言葉を浪費する男。亡き妻のために毎日「おはよう」と使い続ける。悠に一つの問いを
　投げかける。「応答を待たずに使い続ける言葉が、届いていると思うか？」
・言葉で嘘をつく商人。言葉を買い、偽りの告白を売る。悠に賭けを仕掛ける——届かない
　言葉を届けられなければ、商館に言葉を差し出せ。悠は賭けに敗れ、残語の十分の一を
　失う。
・生まれてくる子のために言葉を残す妊婦。彼女は悠に、受け取り手のいない言葉は
　「誰かが応答するのを待つ」ものであり、応答しなかった過去の自分に届くのだと示す。

そして悠は、自分自身が八歳のとき「ごめんね」を受け取れなかった者であることに
気づく。老女の「ごめんなさい」は、応答しなかった誰かを探している。

三日目、老女が死ぬ。言葉は届かなかった。悠は規則の「精神」を読み替え、「ごめんな
さい」に、かつて応答しなかった自分が「応答」する——彼は自分の残語の半分を費やし
て、その一語に応える。彼は初めて自分の言葉を本心のために使う。

代償は大きい。悠の残語は、もう数年分しかない。

受け取られることのない言葉に、意味はあるのか——物語はその問いを、開いたまま閉じる。
```
