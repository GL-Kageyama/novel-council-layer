# 場面1　事件の再会

引き継ぎというのは、要するに、捨てることだった。

沢木は資料室で、段ボールを上から順に開けていた。十四箱ある。ガムテープを剥がす音が、蛍光灯の下で乾いていた。

「先輩、全部開けるんですか」

戸口から伊原が言った。手に缶コーヒーが二本ある。

「開けないと捨てられん」

「開けたら捨てないでしょう」

「よく見てるな。刑事に向いてる」

伊原は一本を机の端に置いて、出ていった。沢木は蓋を閉じ、油性ペンで箱の腹に番号を書いた。一、二、三。書いた数だけ廊下へ出した。

七箱目の底に、色の褪せたファイルが一冊あった。

背のラベルは半分かすれていた。二十年前の日付。少女、と読めた。

沢木はそれを膝に置いた。開かないまま、しばらく持っていた。缶はまだ温かかった。プルタブを起こし、一口飲んで、机に戻した。

窓は西を向いている。この時間だけ、埃が見える。埃はゆっくり落ちて、床に着く前に、また舞った。

沢木はファイルの角を、親指で二度、弾いた。

八箱目を開けた。九箱目を開けた。番号を書き、廊下へ出した。十四まで書いて、廊下の箱を数えた。十三あった。

机の上に、ファイルが一冊残っていた。


# 場面2　見逃しの発見

ファイルは薄かった。

聞き込みの記録が十二枚。写真が三枚。少女の顔は、学校の集合写真から切り出したものだった。左肩に、誰かの手が写っている。切り落とせなかったらしい。

沢木は一枚ずつ読んだ。読む速さは二十年前と変わらなかった。

七枚目に、通り沿いの米屋の主人の供述があった。少女を見たのは五時四十分。街灯はもう点いていた、とある。

十一枚目に、同じ主人の再聴取があった。六時十分。街灯はまだ点いていなかった、とある。

沢木は二枚を並べた。並べれば、誰にでも分かる。三十分。

十一枚目の欄外に、青いボールペンで「訂正」と書いてあった。沢木の字だった。

廊下で笑い声がした。誰かが誰かをからかっていた。沢木は二枚を持って、コピー機の前へ行った。蓋を開け、並べて置いて、閉じた。光が二度、走った。

「先輩」

伊原がコピー機の横に立っていた。

「それ、終わった事件です」

「終わってない」

「見つかってない、って意味ですか」

「そういう意味だ」

伊原は少し黙って、それから言った。「退職、来月ですよ」

「来月まである」

沢木はコピーを二つ折りにして、上着の内側に入れた。原本はファイルに戻した。ファイルは、机の上に置いたままにした。


# 場面3　追跡の開始

米屋は無くなっていた。一階はコインランドリーで、乾燥機が三台、回っていた。主人は二階に住んでいた。八十を越えていた。

「刑事さん」と老人は言った。「久しぶりだね」

「覚えてますか」

「顔は忘れた。声は覚えてる」

沢木は湯呑みを受け取った。茶は薄かった。窓は駅の方を向いていて、開いていた。拡声器の音が入ってくる。名前を繰り返している。老人は窓を閉めなかった。

「街灯のことなんですが」

「街灯」

「あの日、点いていましたか」

老人はしばらく考えた。「点いてたよ」

「調書には、点いていなかったと」

「ああ」老人は湯呑みを置いた。「あれは、直してもらったんだ」

「直した」

「市役所の子が来てね。あの年の日の入りを調べてくれた。街灯が点くのは六時二十分だって。じゃあ私の見間違いだ、と。親切な子でね。あんたらより先に来た」

「来たのは、いつです」

「あんたらが二度目に来る、前の日」

「名前は」

「忘れた」老人は窓の外へ顎をやった。「今、偉くなったろ。あの子だよ。町内でも評判がいい」

沢木は茶を飲んだ。薄いままだった。

署に戻ると、課長に呼ばれた。

「沢木さん、有給が二十日残ってます」

「知ってます」

「消化してください」

「二十日、何をすれば」

「旅行でも」課長は書類を見たままだった。「引き継ぎは伊原がやります」

廊下で伊原とすれ違った。伊原は缶コーヒーを持っていなかった。


# 場面4　板挟み

机の上のファイルは、無かった。

七番の箱は資料室に戻され、ガムテープが新しくなっていた。端がきれいに折り返してある。沢木の折り方ではなかった。

沢木は上着の内側に手を入れた。二つ折りの紙は、そこにあった。

電話が鳴ったのは、その夜だった。

「沢木さんでいらっしゃいますか」

若い男の声で、丁寧だった。

「そうです」

「長い間、お疲れさまでした」

「まだ来月です」

「存じております」

男は天気の話をした。週末は晴れるらしい、と言った。退職の日が良い日になるといい、というようなことも言った。切れた。番号は残っていなかった。

台所で、挨拶の下書きを書いた。「三十年間」と書いて、消した。「みなさまには」と書いて、消した。三行書いて、三行消した。

換気扇が回っていた。止めると静かになりすぎたので、また回した。

紙をもう一枚、横に置いた。二つ折りの紙だった。開くと、五時四十分と六時十分が並んでいた。

翌日、伊原が来た。玄関で、靴を履いたまま立っていた。

「先輩、花束、何色がいいですか」

「花束はいい」

「規則です」

「規則か」

「規則です」伊原は目を上げなかった。「先輩。あと二十日、休んでください。俺、引き継ぎますから」

「引き継ぐのか」

「引き継ぎます」

伊原は帰った。沢木は三和土に、しばらく立っていた。

それから台所へ戻り、下書きとコピーを、両方とも上着の内側に入れた。


# 場面5　選択と結末

退職の日は晴れた。電話の男の言った通りだった。

辞令は三十秒で終わった。署長が読み、沢木が受け取り、拍手が鳴った。花束は赤と白で、重かった。

「では、沢木さんから一言」

沢木は前に出た。花束を机に置き、上着の内側から紙を出した。二枚あった。一枚を戻した。

「五時四十分」と沢木は言った。

署長が顔を上げた。

「六時十分。二十年前の九月、米屋の主人が、少女を見た時刻です。調書に二つ書いてあります。三十分、違います」

咳をする者がいた。それきり、誰も咳をしなかった。

「二枚目の欄外に、訂正、と書いてあります。私の字です」

沢木は紙を折った。

「少女は、まだ見つかっていません。以上です」

拍手はなかった。椅子が一つ鳴った。沢木は席へ戻らず、そのまま廊下へ出た。

伊原が追ってきた。

「先輩」

「なんだ」

「どこへ行くんです」

「駅前だ」

「演説、やってますよ」

「知ってる」

伊原は少し黙った。「花束、預かります」

「頼む」

正面玄関を出た。手帳は朝、返した。内側に残っているのは、二つ折りの紙だけだった。

駅前まで歩いて十五分ある。拡声器の声が、だんだん大きくなった。清潔な声だった。この街を、と言っていた。もう一度、と言っていた。朽木でございます、と言っていた。

信号で止まった。沢木は時計を見た。五時四十分。

信号が変わった。街灯が、点いた。

沢木は渡った。
