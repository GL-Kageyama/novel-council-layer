# 場面3　追跡の開始

沢木は、二十年前の商店を訪ねた。店はまだあった。主は、腰を曲げて、店の前を掃いていた。

「四時半。駅前のほうへ。間違いありませんよ」主は、ほうきを動かしたまま、言った。「あの子の後ろを、男が一人。市役所の、若いのでした」

「男の顔は」

「若かったから。顔は、浮かばんです」

帰り道、選挙ポスターが目に入った。朽木の顔と、「清廉」の二文字が、そこにあった。

沢木は、車を路肩に止めた。ポスターの顔を、じっと見た。

朽木は、二十年前、市役所の若い職員だった。主の言葉が、重なった。

沢木は、ポスターから、しばらく目を離せなかった。

沢木の携帯が鳴った。伊原だった。

「朽木の秘書から、連絡がありました。今さら、やめておけと」

沢木は、電話を切った。ハンドルを握る手に、力が入った。
