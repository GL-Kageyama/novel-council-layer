# 場面1　事件の再会

引き継ぎというのは、要するに、捨てることだった。

沢木は資料室で、段ボールを上から順に開けていた。十四箱ある。ガムテープを剥がす音が、蛍光灯の下で乾いていた。

「先輩、全部開けるんですか」

戸口から伊原が言った。手に缶コーヒーが二本ある。

「開けないと捨てられん」

「開けたら捨てないでしょう」

「よく見てるな。刑事に向いてる」

伊原は一本を机の端に置いて、出ていった。沢木は蓋を閉じ、油性ペンで箱の腹に番号を書いた。一、二、三。書いた数だけ廊下へ出した。

七箱目の底に、色の褪せたファイルが一冊あった。

背のラベルは半分かすれていた。二十年前の日付。少女、と読めた。

沢木はそれを膝に置いた。開かないまま、しばらく持っていた。缶はまだ温かかった。プルタブを起こし、一口飲んで、机に戻した。

窓は西を向いている。この時間だけ、埃が見える。埃はゆっくり落ちて、床に着く前に、また舞った。

沢木はファイルの角を、親指で二度、弾いた。

八箱目を開けた。九箱目を開けた。番号を書き、廊下へ出した。十四まで書いて、廊下の箱を数えた。十三あった。

机の上に、ファイルが一冊残っていた。
