# 場面1　記録の再会

退職まで、あと十日。

水野は引き継ぎという名の整理を始めた。詰所の棚を上から順に開けて、要るものと要らないものに分ける。要らないもののほうが多い。乾いたペンが三本。切れかけた輪ゴム。マグカップの底に、白く固まった粉のあと。

古い記録は段ボールに積んだ。古いものから。十年分が、棚に寝たままだった。

いちばん下の段ボールを開けたとき、ほこりが立った。水野は咳を一つした。

表紙の色あせた記録が、いちばん上にあった。綴じ目が緩んでいて、輪ゴムが掛けてある。輪ゴムは、指で触れると、粉になって落ちた。

「観察記録」と、表紙にあった。日付は、二十年前の九月。

要らないほうの段ボールへ入れようとして、手を止めた。

# 場面2　見逃しの発見

水野は、記録を台の上に置いた。

観察の記述を、一枚ずつ繰る。観察。バイタル。投薬メモ。二十年前の字は、どれも薄い。

夜勤の観察メモに、こうあった。二十一時、患者は眠っている。二十三時、患者は眠っていない、とある。

二時間。その二時間の間に、何があったのか、どこにも書いてなかった。

水野は、そのページを、何度も行ったり来たりした。この記録を綴じたのは、自分だ。水野の判が、いちばん下に押してあった。

「まだやってたんですか」

主任が、詰所の入り口に立っていた。

「終わった記録ですよ、これは」

「あと十日で、私も終わるの。終わる者同士、つきあってみる？」

水野は、ページを閉じずに言った。

# 場面3　追跡の開始

水野は、二十年前の当直表を探した。事務所はまだあった。事務員は、腰を曲げて、棚の前を拭いていた。

「二十三時。あの夜、誰が当直でしたか」

「若い先生が、一人。外科の、若いのでした」事務員は、雑巾を動かしたまま、言った。

「名前は」

「若かったから。名前は、出ません」

帰り道、掲示板が目に入った。外科部長の顔と、「名医」の二文字が、そこにあった。

水野は、足を止めた。ポスターの顔を、じっと見た。

外科部長は、二十年前、外科の若手医師だった。事務員の言葉が、重なった。

水野は、ポスターから、しばらく目を離せなかった。

水野の携帯が鳴った。主任だった。

「外科部長の秘書から、連絡がありました。今さら、やめておけと」

水野は、電話を切った。携帯を握る手に、力が入った。

# 場面4　板挟み

夜。水野は、詰所の台に、記録を広げた。

封筒が一つ、記録の隣にあった。差出人は、外科部長の事務所だった。開けていなかった。

水野は、封筒をゴミ箱へ入れた。手を伸ばして、封筒を拾った。また、台に置いた。

退職まで、あと三日。退職したら、まず、長く眠る。目覚ましを、もう買わない。それだけを、決めていた。

水野は、記録を閉じて、鞄に戻した。封筒は、開けずに、ゴミ箱へ入れた。

# 場面5　選択と結末

退職の日。

辞令と、花束と、拍手。水野は、皆の前で、頭を下げた。

机も、棚も、空だった。

水野は、観察記録を開いた。自分の判が押してあるページを、開いたまま、主任の机の上に置いた。

詰所を出た。桜は、もう、散っていた。

水野は、家のほうへは帰らなかった。病棟のほうへ、歩いて行った。
