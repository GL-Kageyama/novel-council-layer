# 場面1　記録の再会

引き継ぎというのは、要するに、捨てることだった。

水野はナースステーションの奥で、古い記録の箱を上から順に開けていた。十二箱ある。ガムテープを剥がす音が、深夜の静けさに乾いていた。

「水野さん、全部開けるんですか」

配膳台の向こうから主任が言った。手にマグカップが二つある。

「開けないと捨てられないでしょう」

「開けたら捨てられないでしょ」

「よく見てるわね。看護師に向いてる」

主任は一つを台の端に置いて、詰所を出ていった。水野は蓋を閉じ、油性ペンで箱の腹に番号を書いた。一、二、三。書いた数だけ、廊下へ出した。

六箱目の底に、色の褪せた観察記録が一冊あった。

背のラベルは半分かすれていた。二十年前の日付。患者の名は、読めなかった。

水野はそれを膝に置いた。開かないまま、しばらく持っていた。マグはまだ温かかった。一口飲んで、台に戻した。

詰所の灯りは、夜勤の間ずっと点いている。この時間だけ、埃が見える。埃はゆっくり落ちて、床に着く前に、また舞った。

水野は記録の角を、親指で二度、弾いた。

七箱目を開けた。八箱目を開けた。番号を書き、廊下へ出した。十二まで書いて、廊下の箱を数えた。十一あった。

台の上に、記録が一冊残っていた。

# 場面2　見逃しの発見

記録は薄かった。

観察の記述が十二枚。バイタルの数値が三枚。患者の顔は、退院の集合写真から切り出したものだった。左肩に、誰かの手が写っている。切り落とせなかったらしい。

水野は一枚ずつ読んだ。読む速さは二十年前と変わらなかった。

七枚目に、夜勤の観察記録があった。二十一時、患者は眠っている、とある。点滴は五〇〇、とある。

十一枚目に、同じ夜の再記録があった。二十三時、患者は眠っていない、とある。点滴は四〇〇、とある。

水野は二枚を並べた。並べれば、誰にでも分かる。二時間、点滴が一〇〇、違う。

十一枚目の欄外に、青いボールペンで「訂正」と書いてあった。水野の字だった。

詰所の奥で、電話が鳴った。誰かが誰かに、小声で話していた。水野は二枚を持って、コピー機の前へ行った。蓋を開け、並べて置いて、閉じた。光が二度、走った。

「水野さん」

主任がコピー機の横に立っていた。

「それ、終わった記録です」

「終わってない」

「見つかってない、って意味ですか」

「そういう意味」

主任は少し黙って、それから言った。「定年、来月ですよ」

「来月まである」

水野はコピーを二つ折りにして、胸ポケットに入れた。原本は記録に戻した。記録は、台の上に置いたままにした。

# 場面3　追跡の開始

水野は、二十年前の当直表を探した。事務所はまだあった。管理している事務員は、残っていた。

「看護師さん」と事務員は言った。「久しぶりだね」

「覚えてますか」

「顔は忘れた。字は覚えてる」

水野は記録の写しを差し出した。紙は薄かった。窓は廊下の方を向いていて、開いていた。放送の音が入ってくる。誰かの名前を繰り返している。事務員は窓を閉めなかった。

「当直のことなんですが」

「当直」

「あの夜、誰がいましたか」

事務員はしばらく考えた。「外科の、若い先生がいたよ」

「記録には、いなかったと」

「ああ」事務員は写しを置いた。「あれは、直してもらったんだ」

「直した」

「外科部長が来てね。あの年の当直表を調べてくれた。あの夜は、もう帰っていたって。じゃあ私の見間違いだ、と。親切な先生でね。あんたらより先に来た」

「来たのは、いつです」

「あんたらが二度目に来る、前の日」

「名前は」

「忘れた」事務員は窓の外へ顎をやった。「今、偉くなったろ。あの先生だよ。病院でも評判がいい」

水野は写しを胸ポケットに戻した。紙は薄いままだった。

詰所に戻ると、師長に呼ばれた。

「水野さん、有給が二十日残ってます」

「知ってます」

「消化してください」

「二十日、何をすれば」

「旅行でも」師長は書類を見たままだった。「引き継ぎは主任がやります」

廊下で主任とすれ違った。主任はマグカップを持っていなかった。

# 場面4　板挟み

台の上の記録は、無かった。

六番の箱は倉庫に戻され、ガムテープが新しくなっていた。端がきれいに折り返してある。水野の折り方ではなかった。

水野は胸ポケットに手を当てた。二つ折りの紙は、そこにあった。

電話が鳴ったのは、その夜だった。

「水野さんでいらっしゃいますか」

若い女の声で、丁寧だった。

「そうです」

「長い間、お疲れさまでした」

「まだ来月です」

「存じております」

女は天気の話をした。週末は晴れるらしい、と言った。退職の日が良い日になるといい、というようなことも言った。切れた。番号は残っていなかった。

詰所で、挨拶の下書きを書いた。「三十年間」と書いて、消した。「みなさまには」と書いて、消した。三行書いて、三行消した。

換気扇が回っていた。止めると静かになりすぎたので、また回した。

紙をもう一枚、横に置いた。二つ折りの紙だった。開くと、二十一時と二十三時が並んでいた。

翌日、主任が来た。詰所の入口で、白衣のまま立っていた。

「水野さん、花束、何色がいいですか」

「花束はいい」

「規則です」

「規則か」

「規則です」主任は目を上げなかった。「水野さん。あと二十日、休んでください。私、引き継ぎますから」

「引き継ぐの」

「引き継ぎます」

主任は帰った。水野は詰所の床に、しばらく立っていた。

それから台へ戻り、下書きと写しを、両方とも胸ポケットに入れた。

# 場面5　選択と結末

退職の日は晴れた。電話の女の言った通りだった。

辞令は三十秒で終わった。院長が読み、水野が受け取り、拍手が鳴った。花束は白と薄い青で、軽かった。

「では、水野さんから一言」

水野は前に出た。花束を台に置き、胸ポケットから紙を出した。二枚あった。一枚を戻した。

「二十一時」と水野は言った。

院長が顔を上げた。

「二十三時。二十年前の九月、夜勤の観察記録です。記録に二つ書いてあります。二時間、点滴が一〇〇、違います」

咳をする者がいた。それきり、誰も咳をしなかった。

「二枚目の欄外に、訂正、と書いてあります。私の字です」

水野は紙を折った。

「患者は、あの夜のあと、記録にありません。以上です」

拍手はなかった。椅子が一つ鳴った。水野は席へ戻らず、そのまま廊下へ出た。

主任が追ってきた。

「水野さん」

「なに」

「どこへ行くんです」

「外来だ」

「先生、いらっしゃいますよ」

「知ってる」

主任は少し黙った。「花束、預かります」

「頼む」

正面玄関を出た。ネームプレートは朝、返した。胸ポケットに残っているのは、二つ折りの紙だけだった。

外来まで歩いて五分ある。声が、だんだん大きくなった。静かな声だった。この病院を、と言っていた。もう一度、と言っていた。

廊下で止まった。水野は、ネームプレートのあった胸元に、一度だけ手をやった。

灯りが、点いた。

水野は歩き出した。
