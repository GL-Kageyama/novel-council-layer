# V2 共通 premise（固定）

## 検証
V2「ロールの効果」—— design.md の「人物」欄にロール小見出し（賭け／挑戦／能動の原理）を付けた場合と付けない場合で、fast-draft の草稿の「らしさ・自律性」が変わるか。

## premise（A・B 共通。この原文を変えない）

引退まで一ヶ月のベテラン刑事・沢木（さわき、五十八歳）は、二十年前に自分が見逃した少女失踪事件の真相を、退職までの最後の仕事として追う。手がかりを辿るうち、その事件の真相が、いま再選を目指す市長候補の過去に繋がっていることが見えてくる。

## 変数（A・B で変えるのはここだけ）

| 版 | character-forge の実施範囲 | design.md の「人物」欄 |
|---|---|---|
| A（対象） | 手順 2（核）＋ **2b（ロール確定）** まで実施 | ロール小見出し（賭け／挑戦／能動の原理）を埋める |
| B（対照） | 手順 2（核＝欲求・動機・傷・信念）まで | ロール小見出しなし（従来どおり核のみ） |

- 沢木以外の人物（市長候補・少女・同僚刑事）は両版で同一に保つ。
- 事件・結末・場面の骨格も同一に保つ。変えるのは沢木の「ロール欄の有無」だけ。
