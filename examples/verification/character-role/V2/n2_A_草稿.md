# V2 n=2-A 草稿（ロール確定あり）

定年まであと三ヶ月。西園は詰所のロッカーを整理していた。使い古した手帳の奥から、二十年前の患者記録が出てきた。亡くなった患者の名が、今も忘れられない。西園は記録を破らず、看護師の鞄に入れた。

記録を読み返し、西園は指を止めた。死亡時刻の記録が、二つのカルテで食い違っている。しかも、一方の記載は後から書き換えた痕跡があった。二十年前、なぜ気づかなかった。いや、見ないふりをしたのかもしれない。同僚が「昔のことは、もう」と声をかけた。西園は記録から顔を上げず、「まだ終わってない」とだけ言った。

西園は当時の関係者を一人ずつ訪ねた。口を閉ざす者、目を逸らす者ばかりだった。隠蔽の糸は、いま再任を控えた理事長の足元へ、静かに伸びていった。ある夜、西園の自宅に、名乗らない電話が一度だけ鳴った。西園は何も言わず受話器を置き、翌朝も変わらず関係者を訪ねた。

理事長の秘書だという男が、病院へ来た。「定年間際の看護師さんが、余計なことを」と、笑いながら帰っていった。黙っていれば平穏があった。退職後の、なんでもない余生が。西園はその余生を、二十年前に見送った患者に渡してよいのか、と自分に問うた。渡せない。彼女は看護師を、最後まで看護師として終える道を選んだ。

退職の日。西園は隠蔽へ繋がる記録を、県の医療審査会に届けてから出勤した。ロッカーは空っぽだった。整理された詰所だけが、静かに残っていた。
