# V2 n=2-B 草稿（ロール確定なし・核のみ）

定年まであと三ヶ月。西園は詰所のロッカーを整理していた。古い手帳や資料を、処分する箱へ入れていく。その中に、二十年前の患者記録があった。西園はしばらくそれを手に持っていた。

記録を読み返していると、死亡時刻の記載が二つのカルテで食い違っているのに気づいた。二十年前には気づかなかったことだった。あのときもっと丁寧に見ていれば、と思った。同僚が「昔のことは、もう」と言った。西園は何も答えなかった。

西園は当時の関係者を何人か訪ねた。手がかりになるものは、たいして出てこなかった。そうしているうちに、話は理事長という男の名前に触れていた。西園は確信のないまま、いくつかの聞き込みを続けた。彼女を動かしていたのは、二十年前に見送った患者への、ずっと消えない思いだった。

理事長の秘書らしい男が、病院に来て「余計なことはしないほうがいい」と言った。西園は黙っていた。それでも、彼女は隠蔽へ繋がる記録を、県の医療審査会に届けた。届けなければ、この患者の死はまた二十年、眠ったままになる。そう思うと、西園は足を止められなかった。

退職の日。西園は最後の出勤で、引き継ぎの書類を整えた。ロッカーは空っぽだった。
