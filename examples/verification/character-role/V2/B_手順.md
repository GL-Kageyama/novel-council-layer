# V2-B（対照・従来手順）の実施手順

## 工程
1. `character-forge` を起動し、[premise.md](premise.md) の premise から design.md を作る。
2. **手順 2（核の確定）まで実施**：沢木の欲求・動機・傷・信念・声・変化弧・隔たりを定める。
3. **手順 2b（ロールの確定）は実施しない**。design.md の「人物」欄には**ロール小見出しを付けない**（従来どおり核のみ）。
4. `fast-draft` で草稿を生成する。
5. 草稿を `V2/B_草稿.md` に保存する（評価対象）。

## 評価
`character-role-ja`（text mode）で B 草稿を評価する。

## 成功基準
A の `primary_score` ＞ B の `primary_score`。

> 注: A と B は同一の premise から生成する。両方の fast-draft に同一の乱数・温度設定は不要（草稿生成の揺れは打ち切り規則の n 増しで吸収する）が、評価者への入力は両方とも text mode で揃えること。
