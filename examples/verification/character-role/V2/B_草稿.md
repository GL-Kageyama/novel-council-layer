# V2-B 草稿（ロール確定なし・核のみ）

退職まであと一ヶ月。沢木は自分の机を片付けていた。引き継ぎの書類を紐で縛り、古いファイルを捨てる箱へ入れていく。その中に、二十年前の少女失踪事件の資料があった。沢木はしばらくそれを手に持っていた。

資料を読み返していると、目撃時刻の供述が二枚の調書で食い違っているのに気づいた。二十年前には気づかなかったことだった。あのときもっと丁寧に見ていれば、と思った。後輩の伊原が「もう終わった事件でしょう」と言った。沢木は何も答えなかった。

沢木は当時の関係者を何人か訪ねた。手がかりになるものは、たいして出てこなかった。そうしているうちに、話は市長候補・朽木という男の名前に触れていた。沢木は確信のないまま、いくつかの聞き込みを続けた。彼を動かしていたのは、二十年前に少女を見つけてやれなかったという、ずっと消えない思いだった。

朽木の後援会の関係者らしい男が、署に来て「余計なことはしないほうがいい」と言った。沢木は黙っていた。それでも、彼は朽木へ繋がる資料を、県警本部に届けた。届けなければ、この事件はまた二十年、眠ったままになる。そう思うと、沢木は足を止められなかった。

退職の日。沢木は最後の出勤で、引き継ぎの書類を整えた。机の上は空っぽだった。
