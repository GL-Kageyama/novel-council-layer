# V2-A（対象・ロール確定）の実施手順

## 工程
1. `character-forge` を起動し、[premise.md](premise.md) の premise から design.md を作る。
2. **手順 2（核の確定）まで実施**：沢木の欲求・動機・傷・信念・声・変化弧・隔たりを定める。
3. **手順 2b（ロールの確定）まで実施**し、design.md の「人物」欄に**ロール小見出し**を埋める。内容は以下を明記：
   - **賭け**（失い得るもの）：沢木が何を失い得るか。欲求・傷を物語の因果に接続する。
   - **挑戦**（立ち向かうもの）：対象・敵・障壁（市長候補、あるいは過去の自分の過失）。
   - **能動の原理**（どう動くかのルール）：核はリスクテイク。「XのためならZを犠牲にできる」を名指す。
4. `fast-draft` で草稿を生成する。
5. 草稿を `V2/A_草稿.md` に保存する（評価対象）。

## 評価
`character-role-ja`（text mode）で A 草稿を評価する。

## 成功基準
A の `primary_score` ＞ B の `primary_score`（らしさ・自律性＝ consistency・autonomy の上昇を期待）。
