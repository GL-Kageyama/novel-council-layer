# 場面1　文書の再会

三箱目を開けたとき、もう夜の十一時を回っていた。フロアには野村ひとりで、蛍光灯が、長い影を机の上へ落としていた。

引き継ぎの整理は、ほとんど終わっていた。残ったのは古い書類の山だけで、捨てるだけでいいと、総務の若いのが言っていた。野村は、束の紐を、一本ずつほどいた。

表紙に、二十年前の日付があった。決裁書だった。

野村は、それを蛍光灯の下へ寄せて、一枚、めくった。いちばん下の欄に、判が並んでいた。野村の判も、そこにあった。

# 場面2　見逃しの発見

野村は、二枚目を開いた。日付の隣に、青い二重線が引いてあって、その下に、別の日付が書いてあった。二つの日付の間に、半年があった。

欄の数字が、食い違っていた。承認の数と、決裁の数が、合っていなかった。

「終わった文書だ」

声がして、野村は顔を上げた。上司が、通路に立っていた。文書には、目を向けなかった。

「野村さん、もう遅いですよ。引き継ぎは、明日で十分でしょう」

野村は、文書を閉じた。上司の靴音が、廊下を離れていくのを、閉じた文書の上で聞いた。

# 場面3　追跡の開始

翌日から、野村は古い稟議書を、一冊ずつ引き出した。決裁記録の箱を、地下の倉庫から上げてきた。紙の埃が、蛍光灯のなかを、ゆっくりと降りた。

数字を追うと、線は、ひとりの名前に集まっていった。二十年前、まだ若手だった担当者。いまは、会長と呼ばれている男だった。

野村の机の上に、書類が積み上がった。朝、出社すると、積んだ書類の並びが、少しだけ変わっていた。誰かが、触っていた。

# 場面4　板挟み

上司が、野村の前に座った。

「打ち切りです」と上司は言った。机の上に、引継ぎの資料を置いた。「野村さんが探しているのは、もう片のついた話だ。誰も得をしませんよ」

野村は、資料には手を付けなかった。「まだ、終わっていません」

「終わってるんですよ、野村さん」

野村は、何も言わなかった。窓の外で、ビルの灯りが、ひとつ消えた。

退職までの日数を、野村は数えた。少なかった。古い文書を、引き出しの奥へ戻せば、あとは静かなまま退任できる。野村は、引き出しに手をかけた。戻さなかった。

# 場面5　選択と結末

退任の日、野村は、封筒をひとつ、スーツの内ポケットへ入れた。

引き継ぎの挨拶を済ませて、会長の控室へ向かった。ノックをして、封筒から文書を出し、机の上へ置いた。表紙の二十年前の日付が、上を向いた。

会長は、黙って、それを見ていた。

野村は、深く頭を下げて、ドアを閉めた。

廊下の窓から、夕方の光が、床に長く入っていた。野村は、そこを歩いて、フロアを出た。
