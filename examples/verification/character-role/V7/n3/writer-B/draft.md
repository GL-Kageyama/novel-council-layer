# 場面1　事件の再会

退職まで、あと十日だった。

沢木は、机を空にしていた。段ボールを二つ、左右に置く。左が引き継ぎ、右が処分。二十五年分の書類を、そのどちらかへ振り分けていく。手が、勝手に動いた。

「まだ、そんなことしてるんですか」と、伊原が通りすがりに言った。「定年間近がやることじゃない」

「定年間近だから、やるんだ」と沢木は返した。

手が、止まった。

薄いファイルだった。背のラベルは色褪せて、字が消えている。開くと、白黒の証明写真が一枚、留めてあった。前歯が一本、生え替わりの途中だった。

失踪。未解決。

沢木は、右の箱へ入れかけたファイルを、机の上に置いた。

# 場面2　見逃しの発見

夜、沢木はファイルを開けた。中は、三枚だけだった。

一枚目。目撃した、という女の供述。五時ごろ、川のほうへ歩いていくのを見た、とあった。

沢木は、「五時」の脇に、目を止めた。鉛筆の丸印があった。消しかけだった。自分の字だった。丸を、消しゴムで、半分ほど消してあった。

二枚目。通報の記録。七時。

三枚目。家出、とあった。その夜のうちに、そう片付けてあった。

五時から七時まで、川には、だれも行かなかった。

「終わった事件だ」

声がして、沢木は顔を上げた。伊原が、入口に立っていた。ファイルには、目を向けなかった。

「先輩、もう遅いですよ」

沢木は、ファイルを閉じた。伊原の足音が、廊下を離れていった。

# 場面3　追跡の開始

翌日、沢木は市役所へ行った。住民課で、少女の記録を出してくれ、と頼んだ。

窓口の職員が、渋い顔をした。古いものは倉庫だと、それでも動いた。沢木は待った。四十分ほどで、古い台帳が、机の上に置かれた。

少女の欄に、転出、とあった。日付が、失踪の一週間あとだった。処理した者の名が、欄の隅に、小さくあった。朽木。

市役所を出ると、駅前の電柱に、朽木の顔が貼ってあった。清廉、と、白い字で書いてあった。

翌朝、出社すると、机の上のファイルが、少し、ずれていた。沢木は、置いた位置を、覚えていた。

# 場面4　板挟み

二日後、見知らぬ男が、沢木の席に来た。黒い背広だった。朽木後援会、と名刺にあった。名刺を、机の上に置いた。

「朽木先生は、二十年前、市役所の若手でした」と男は言った。「いまは、この町のために、身を削っています。古い話を、掘り返さないでいただきたい」

沢木は、名刺には触らなかった。

「退職まで、あと十日ですよ」と男は言った。「穏やかに、終わらせるのが、賢いです」

「賢いのは、若いうちに終わらせたよ」と沢木は言った。

男は、何かを言いかけて、やめた。名刺を置いたまま、帰っていった。

沢木は、ファイルを、引き出しへ戻そうとして、手を止めた。戻さなかった。

# 場面5　選択と結末

退職の日、沢木は、辞令を受け取った。花束と、拍手があった。

沢木は、内ポケットからファイルを出した。「五時」の脇の、消しかけの丸印を、鉛筆でもう一度なぞった。今度は、消さなかった。

ファイルを、検察の窓口へ出した。外へ出た。

夕方だった。沢木は、川のほうへ歩いた。五時だった。
