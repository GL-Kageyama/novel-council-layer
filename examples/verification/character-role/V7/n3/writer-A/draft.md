# 場面1 事件の再会

退職まで、あと五日。

沢木は机の上の物を、順に段ボールへ移していた。ペン立て。名刺入れ。十数年、机の右隅に置きっぱなしだったマグカップ。どれも箱の底へ、ぽん、ぽん、と落とした。

「先輩、まだ残ってたんですか」

伊原が、ドアのところに立っていた。沢木は振り向かずに、マグカップの取っ手を箱の縁へ掛けた。

「引き継ぎは終わったよ。あとは、がらくたを捨てるだけだ」

「そのがらくたに、二十年分が詰まってるんですけどね」

「だから捨てるんだ」

伊原が、困ったように笑った。沢木も、口の端を上げた。

棚の一番上から、古い資料の束を下ろした。埃が、蛍光灯の下に浮いた。束の間に、ひとつの紙ファイルが、ずれてはさまっていた。表紙に、事件番号と、小さく「失踪」の二字。名前の欄は、空いていた。

沢木は、ファイルを箱へ入れなかった。机の上に置いた。

# 場面2 見逃しの発見

あくる日も、沢木は同じ机に座っていた。

供述調書が十数枚、輪ゴムで束ねてあった。少女が最後に目撃されたのは、夕方の五時。市役所の近くの横断歩道。沢木は、一枚ずつ、頁を繰った。

最後の一枚は、市役所の若い職員の供述だった。朽木。五時には市役所を出ていた、と書いてあった。

沢木は、前の頁へ戻った。別の目撃証言が、市役所の若い職員を、五時過ぎまで窓のあたりに見ていた、と書いてあった。

沢木は、その二枚を、突き合わせた。合わなかった。

供述のいちばん下に、作成者の署名があった。沢木の字だった。

「先輩」

伊原が、いつの間にか、机の前に立っていた。沢木は、ファイルを伏せなかった。

「それ、終わった事件でしょう」

「終わってない」

「時効、とっくに切れてますよ」

沢木は、首を振った。

「時効の話をしてるんじゃない」

伊原は、ファイルの表紙を見た。名前のない表紙を。

「退職まで、四日なんですよ。見なかったことに、できませんか」

沢木は、答えなかった。ファイルを、開いたままにした。

# 場面3 追跡の開始

沢木は、市役所へ足を運んだ。人事の窓口で、当時、若手職員だった男の記録を見たい、と伝えた。

「何の、ご用でしょう」

「警察の者だが」

「退職されるそうですね」

沢木は、少し笑った。

「よくご存じで」

「記録の閲覧は、お断りしています。個人情報ですので」

「当時の、失踪事件の関係者でして。調べたいだけです」

窓口の職員は、奥へ引っ込んだ。戻ってくると、同じことを、もう一度言った。

「お断りしています」

沢木は、市役所を出た。正面の掲示板に、選挙のポスターが貼ってあった。再選を目指す、という顔が、こちらを見ていた。朽木。あの供述の、朽木だった。名前の下に、市長候補、と小さくあった。

沢木は、しばらく、その顔を見ていた。

# 場面4 威圧

沢木は、供述の二枚を、もう一度、突き合わせた。それから、当時、目撃証言を取った相手を、訪ねて歩いた。小さな商店の主だった。店は、もうなかった。

署に、電話が入った。

「沢木さんですね」

名乗らない声だった。

「お辞めになったほうが、よろしいですよ。ご家族も、お疲れでしょう」

沢木は、受話器を置いた。手は、震えていなかった。

夕方、沢木は、段ボール箱の前に立っていた。ファイルを、箱へ入れようとして、やめた。机の上に、戻した。

退職まで、あと三日。

# 場面5 最終対峙

沢木は、会合の帰りを待った。

選挙事務所の前で、黒い車が止まった。沢木が前に出ると、後部座席の窓が、少し下がった。

「どうぞ」

沢木は、後部座席に乗り込んだ。車は、ゆっくり動き出した。

朽木は、しばらく、窓の外を見ていた。それから、静かに言った。

「退職まで、あと三日でしたね」

「ええ」

「三日、黙っていてください。それで済む」

沢木は、答えなかった。

「後は、好きに暮らせばいい。釣りでも、畑でも。警察のことは、忘れて」

車が、赤信号で止まった。

「二十年前の、あの子のことは、もう、誰も覚えていません。あなた以外は」

沢木は、朽木の横顔を見た。清廉な顔をしていた。

「覚えていなくても、います」

朽木は、初めて、沢木のほうを向いた。

「そうしますと、あなたは、退職できなくなりますよ」

「かまいません」

沢木は、ドアを開けた。夜の風が、入ってきた。

車は、信号が変わると、走り去った。沢木は、歩道に立っていた。胸のポケットの、供述の写し二枚に、手をやった。折り目を、指でなぞった。
