# 場面1　記録の再会

深夜二時を回っていた。処置室の隅で、水野は古い記録の綴りを崩していた。引継ぎの前の整理だった。棚から下ろした段ボールを開け、一冊ずつ紐を解き、表紙の日付を確かめて、新しい箱へ移す。その繰り返しだった。

二十年も前の紙は、黄ばんでいた。

一冊の表紙の端に、自分の字を見つけた。ボールペンの青で、観察記録とだけ。水野は手を止めた。頁を開くと、欄外に同じ青が並んでいた。自分の字だと、すぐにわかった。書く手の癖は、二十年では変わらない。

水野は、綴りを持ったまま、立っていた。処置室の蛍光灯が、かすかに唸っていた。

# 場面2　見逃しの発見

引継ぎの書類は、まだ手つかずだった。水野は箱の前の椅子に座り、綴りを開いていた。

観察記録は、一枚ずつ、自分の字だった。欄外に時刻、その横に経過の一言。特変なし、と並ぶ青い字の中に、ひとつだけ、そうでない頁があった。深夜一時の欄だった。

そこには、消して書き直した跡があった。消しゴムでこすった紙が薄くなって、裏の頁の文字が透けていた。書き直した字は、自分の字だった。消えた字も、自分の字だった。ひとつの欄に、自分の字が、二度、書かれていた。

「水野さん」

主任が、入り口に立っていた。

「それ、終わった記録でしょう」主任は言った。「処分する箱のほうじゃないの」

水野は、頁を開いたままにした。指先で、薄くなった紙を確かめた。

「明日の引継ぎに間に合わせて」主任の声は、低かった。

水野は頷いた。綴りを閉じた。閉じた表紙の日付に、目を置いたままだった。

# 場面3　追跡の開始

水野は、当直表から始めた。看護部の棚の、いちばん奥に、二十年分の当直表が並んでいた。それを、二十年前の春まで、月ごとに戻した。

その日の外科当直の欄に、医師の名があった。若い字で書かれた名。いまは、部長と呼ばれる名だった。深夜一時の欄の横に、呼び出し、と小さく書いてあった。

処置記録を、水野は見たくなった。記録庫の前で、事務の男に止められた。

「古い記録の閲覧は、申請が要ります」男は、書類を出した。「師長の判をもらってください」

水野は、書類を受け取った。欄は、すべて空だった。

「二十年前の、ある夜の記録です」水野は言った。

「何年でも同じです」男は言った。「判が要ります」

水野は、当直表の頁を、折らなかった。指で、名前の上を、なぞった。

# 場面4　威圧

明け方近く、師長が処置室へ来た。

「水野さん、聞いたわよ」師長は、水野の前の綴りを見下ろした。「古い記録を、何に使うの」

「確認したいことがあります」水野は言った。

「終わった記録でしょう」師長は、綴りの表紙を、指で弾いた。「あなた、定年まであとどれだけ？いま掘り返して、誰が得をするの」

水野は、答えなかった。

「静かに勤め上げるのが、いちばんいいのよ」師長の声は、柔らかかった。「あなたも、そう思って、ここまで来たんでしょう」

水野は、綴りの頁を開けた。自分の字が、二度、書かれていた。消えた字と、書かれた字。

「わかったわね」師長は言って、出て行った。

水野は、綴りを閉じた。閉じて、また、開けた。薄くなった紙に、指先を、置いた。

# 場面5　最終対峙と結末

面談室は、蛍光灯が点いていた。まだ、外は暗かった。部長は、水野の向かいに座った。白衣の襟は、糊がきいていた。

「お話は伺いました」部長は、笑った。「二十年も前の、夜勤の一晩のことですね」

水野は、綴りを、膝の上に置いていた。

「あなたは、長く勤められました」部長は言った。「定年まで、静かに勤め上げれば、あとは、何も言いません。患者さんのためにも、それがいい」

水野は、膝の上の綴りを見た。表紙の日付。自分の字。消えた字と、書かれた字。

水野は、立ち上がらなかった。座ったまま、綴りを開き、消えた字の頁を、机の上へ、突き出した。

「これは、私が、消した字です」水野は言った。

部長の笑みが、止まった。何か言いかけて、やめた。

窓の外が、白みかけていた。
