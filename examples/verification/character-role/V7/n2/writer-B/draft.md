# 場面1　記録の再会

消灯は、とっくに済んでいた。病棟には水野ひとりで、ナースステーションの蛍光灯だけが、長い影をカウンターへ落としていた。

引き継ぎの整理は、ほとんど終わっていた。残ったのは古い記録の山で、捨てるだけでいいと、若い看護師が言っていた。水野は、束の紐を、一本ずつほどいた。

表紙に、二十年前の日付があった。観察記録だった。

水野は、それを灯りの下へ寄せて、一枚、めくった。いちばん下の欄に、署名が並んでいた。水野の字も、そこにあった。

# 場面2　見逃しの発見

水野は、二枚目を開いた。時刻の欄に、青い二重線が引いてあって、その下に、別の時刻が書いてあった。二つの時刻の間に、三十分があった。

書き直した字は、水野の字だった。

観察の数字が、その三十分のところだけ、続いていなかった。

「終わった記録だ」

声がして、水野は顔を上げた。主任が、通路に立っていた。記録には、目を向けなかった。

「水野さん、もう遅いですよ。整理は、明日で十分でしょう」

水野は、記録を閉じた。主任の靴音が、廊下を離れていくのを、閉じた記録の上で聞いた。

# 場面3　追跡の開始

翌日から、水野は古い当直表を、一枚ずつ引き出した。処置記録の箱を、病棟の奥の倉庫から上げてきた。紙の埃が、蛍光灯のなかを、ゆっくりと降りた。

数字を追うと、線は、ひとりの名前に集まっていった。二十年前、まだ当直の若手医師だった男。いまは、外科部長と呼ばれている男だった。

水野の手元に、記録が積み上がった。夜勤を終えて、朝、ナースステーションへ戻ると、積んだ記録の並びが、少しだけ変わっていた。誰かが、触っていた。

# 場面4　板挟み

師長が、水野の前に座った。

「打ち切りです」と師長は言った。カウンターの上に、引き継ぎの書類を置いた。「水野さんが探しているのは、もう片のついた話です。誰も、助かりませんよ」

水野は、書類には手を付けなかった。「まだ、終わっていません」

「終わってるんですよ、水野さん」

水野は、何も言わなかった。廊下の向こうで、病室の灯りが、ひとつ消えた。

退職までの日数を、水野は数えた。少なかった。古い記録を、引き出しの奥へ戻せば、あとは静かなまま退職できる。水野は、引き出しに手をかけた。戻さなかった。

# 場面5　選択と結末

退職の日、水野は、封筒をひとつ、白衣のポケットへ入れた。

引き継ぎを済ませて、外科部長の部屋へ向かった。ノックをして、封筒から記録を出し、机の上へ置いた。表紙の二十年前の日付が、上を向いた。

外科部長は、黙って、それを見ていた。

水野は、深く頭を下げて、ドアを閉めた。

廊下の窓から、夕方の光が、床に長く入っていた。水野は、そこを歩いて、病棟を出た。
