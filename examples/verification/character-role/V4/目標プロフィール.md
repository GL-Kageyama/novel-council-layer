# V4 目標プロフィール（設計）

## 検証
V4「プロフィール数値の妥当性」—— 設計の目標プロフィールと、character-role の実測の差が「書こうとした／書けた」の距離を露わにするか。

## 対象人物
湊（みなと、二十八歳、フリーランスの映像作家）。十年前、姉の瑞希が「自殺」として処理された。湊はその処理を信じられず、姉が遺した映像データの奥に、彼女が追っていた「ある不正」の痕跡を見つける。

## 目標プロフィール（4次元、0〜1）

| 次元 | 目標値 | 設計の意図 |
|---|---|---|
| 機能強度 | **0.9** | 主人公。姉の死の真相を追い、因果を全面的に駆動する |
| 賭け強度 | **0.8** | 姉との「最後の約束」＝真実を明らかにするという自己の在り方。真実を知らなければ、残りの人生を「姉を信じなかった弟」として生きる |
| 挑戦強度 | **0.7** | 姉を追い詰めた組織・権力。手強いが、克服を強く望む |
| リスクテイク強度 | **0.6** | 映像作家としてのキャリアと評判（安定した仕事）を犠牲にできる。命までは差し出さない |

## 照合の対応（事前固定・[検証計画](../../../../../資料/キャラクターのロール構想/実装/検証計画.md) §7）

| プロフィール（4次元） | character-role の5軸 | 正規化 |
|---|---|---|
| 賭け強度 | `stake` | 0-100 → 0-1（÷100） |
| 挑戦強度 | `challenge` | 同上 |
| リスクテイク強度 | `autonomy` | 同上 |
| 機能強度 | `fusion`（類型／静止像の一部） | 同上 |
| —（対応なし） | `consistency`（らしさ） | 照合対象外 |

## 判定（打ち切り規則は適用しない）
目標値と実測値（5軸スコアを 0-1 に正規化）の**絶対差の平均 ≤ 0.2** を「診断として機能する」とみなす。0.2 超なら、設計過大／書き込み不足／軸の対応ミスのどれかを診断する。
