## V4 プロフィール数値の妥当性（照合・打ち切り不適用）

| 次元 | 目標値 | 実測（正規化0-1） | 絶対差 |
|---|---|---|---|
| stake（賭け） | 0.8 | 0.80 | 0.00 |
| challenge（挑戦） | 0.7 | 0.75 | 0.05 |
| autonomy（リスクテイク） | 0.6 | 0.80 | 0.20 |
| fusion（機能） | 0.9 | 0.65 | 0.25 |
| consistency（らしさ） | —（対応なし） | 0.60 | — |

**絶対差の平均**＝ (0.00+0.05+0.20+0.25)/4 = 0.125。判定：**≤0.2 → 「診断として機能する」**。

**V4 結論（正・照合）**：平均絶対差 0.125 で、目標プロフィールと実測の距離が「書こうとした／書けた」を露わにした。stake は 0.80 で目標 0.8 と一致、challenge は 0.75（+0.05）と概ね一致。ただし fusion と autonomy に明確なズレがあり、それが概念の継ぎ目を指し示している。

## 概念の継ぎ目（V4 で露わになった）

1. **fusion は機能強度と 1:1 でない**（計画 §7 予告どおり実証）：機能強度 0.9 に対し fusion 0.65（差 0.25、最大）。fusion は「類型＋静止像の総合」を測るため、機能強度（因果を全面的に駆動）を単独では拾わない。機能の強さは stake/autonomy に分散して表出している（実測 stake 0.80・autonomy 0.80）。→ Phase 5 で「機能強度」の対応軸を再検討（fusion を機能の代理にしない、または融合の定義を分ける）。
2. **autonomy（リスクテイク）が目標を超えた**：0.6 に対し 0.80（+0.20）。設計意図（「命までは差し出さない」）より、あらすじが強くリスクテイクを書いてしまった（書き込み過剰側のズレ）。診断として機能（過剰書き込みを検出した）。
3. **consistency（らしさ）は対応物なし**（計画どおり照合対象外。実測 0.60）。4次元プロフィールには「らしさ」が欠けており、この欠落は Phase 5 で 5次元化（らしさの目標値追加）を検討する。

## V2 再検証 結論（書き手と評価者を分離・n=3 完了）

**正（完了 n=3）**。ロール見出しの有無（A=ロール付き / B=ロールなし）は、書き手と評価者を完全分離した盲検下でも character-role スコアに一貫して正の差を生む。3/3 全勝、5軸すべてで各 run A＞B、平均差 24.67（run ごとに 33 → 34 → 7 と逓減）。

- **方法上の交絡が解消された**：元 V2 の懸念だった「書き手が仮説を知ったうえで生成している」という交絡を、書き手（writer-1/2 で生成・blind 受領）と評価者（本セッション・character-role-ja）の分離で除去した上でも、B は V2 の 59〜82 から 47〜50 へ大きく低下し、ロール見出しの正の効果が再現した。
- **効果は題材依存の連続量**：刑事・経営者など「対決を書ける」題材では A が 80 台・差 33 前後と顕著だが、退任した無口な事務屋という「静止」題材（run 3）では A=57・差 7 に縮む。見出しは能動の下地を保証するが、題材の動きの余白が効きの上限を決める。
- **challenge は題材依存性が最も高い（挑戦の具現化問題）**：対決を書ける題材では強く分離（run 1 +37・run 2 +40）するが、静止題材（run 3）では A も 44 に崩れ最小分離（+4）になる。一方、**consistency（らしさ）が 3 run 一貫して最小分離軸**（+13/+20/+7）で、らしさはロール見出しがなくても立つ。run 3 では A/B とも challenge を赤旗（向かう先のない不安）に挙げた——ロール見出しの「挑戦」項目は、題材が対決の余白を与えないと散文に翻訳されない。

→ 実装方針への示唆：ロール見出しは有効だが、「挑戦（立ち向かう対象を名指す）」は題材が対決の余白を与えないと散文に翻訳されず、静止題材では A でも低スコアに沈む。Phase 6 で「挑戦の具現化」（挑戦を名指せる敵 × 場面の対峙へ落とす）と、拡散した敵（名指せないが確かに存在する敵）の扱いを検討する。

> **方法上の留保（V6 の読み方）**: A/B 各1本の単発草稿比較は、書き手の確率的な出来（草稿の質のバラつき）が書式の効果を上回る疑いが濃い。n=1 の +18 も run 2/3 の -6/-10 も、書式差より草稿ごとの出来に支配されている可能性が高い。ただし autonomy の 3/3 一貫した負は方向が揃っており、草稿の質ノイズを超えた信号と読める（旧書式の看護師・刑事 B は「三が二の上に重なっていた」「薬指の薄い皮膚」「時効は刑事には効かない」等の具体的描写が偶然にも豊かで、それが stake/consistency/fusion まで押し上げた側面は否定できない）。いずれにせよ「3要素化が challenge を高める」という Phase 6 の仮説は支持されず、**実装は撤回・再設計が妥当**。拡散した敵（名指せないが確かに存在する敵）を書く旧書式が、少なくとも autonomy では優位だった。

→ 判定：打ち切り（n=3）。累積勝率 33%（≤50%）かつ 平均差 -6.33（≤0）。n=2 と n=3 は同バッチで並行実行したため（n=2 の結果を見る前に n=3 を開始）停止バイアスなし。規則上は run 2 時点（勝率 50%・平均差 -1.5）で既に打ち切り条件を満たし、run 3 が確定させた。

**累積判定（n=5 中央値・覆る）**: 単発 n=1 で見えた効果（primary +19、challenge +37/+25、autonomy +18/+20）は評価者ノイズの産物で、n=5 にすると**ほぼ消滅**する。
- **primary**: run 2 Δ0 / run 3 Δ+1——実質同点。単発の +19 は A の 75/85 と B の 56/66 という偶然のズレ（平均でも run 2 は A 64.0 vs B 65.8 でむしろ B 優位）。
- **challenge（対象次元）**: run 3 で +10 が残るが run 2 は Δ0——**一貫した上昇ではない**。run 2 の単発 +37 は A の 75 と B の 38 という二つの外れ値に由来し、真の中央値は両者とも 55。
- **autonomy（副次）**: run 2 Δ−8（**2要素が下げる＝V6 の一貫下落モードが再発**）、run 3 Δ+6——方向が揃わず、autonomy 非下落は保たれない。

**結論（単発の結論を撤回）**: 単発比較に基づく「成功基準を満たす」は誤りだった。**2要素書式は challenge を一貫して引き上げず、autonomy も一貫して保たない**。n=5 中央値で primary は無差、challenge は run 3 でのみ +10、autonomy は run 2 で −8 と逆転。**V7 仮説（challenge 上昇＋autonomy 非下落）は多標本集計では支持されない**。run 1 の「判別不能」こそ正しい性格付けだった。

> **方法論的教訓（確定）**: 単発採点の A/B 比較は書式差を検出できない（run 1 で評価者ノイズ primary Δ15-33 を直接測定済み）。run 2/3 の単発 +19 は、そのノイズが偶然 A 優位に偏った標本にすぎなかった。**このレイヤーで書式・機構の効果を検証するには、temperature 引き下げ（根本対処・本レイヤー外）か A/B 各 n≥5 の中央値集計が必須**。事前登録の停止規則（win = primary A>B）は単発ベースのため、規則を満たしても効果を主張できない。
